# CIKS Yönetim — güncelleme paketleri

Bu repoda program kodu bulunmaz. Yalnızca CIKS Yönetim programının **güncelleme (fark) paketleri** yayınlanır.

- Kurulu program açılışta bu repoda yeni sürüm olup olmadığını denetler.
- Yeni sürüm varsa önce veritabanı yedeği alır, sonra paketi uygular.
- Atlanan sürümlerin paketleri sırayla uygulanır.
- Repo herkese açık olduğu için programın içine erişim anahtarı gömülmez.

Paketler proje sahibi tarafından hazırlanır; bu repoya elle dosya eklenmez.
